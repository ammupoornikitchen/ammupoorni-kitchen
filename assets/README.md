Logo usage

- The header currently uses the hosted image from Postimg: https://i.postimg.cc/cHqPKHYs/110827.png
- To use a local copy instead, download the image and save it as `ammupoorni-logo.png` in this folder.
- If you save a local file, update `index.html` to use `assets/ammupoorni-logo.png` or replace the existing `img` `src` value.
- If the image doesn't show, clear your browser cache or hard-refresh (Ctrl+F5).
